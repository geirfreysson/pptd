# Presenting

## Slideshow

Press **⌘↩** to start the slideshow. It plays full screen unless you choose
**View › Slideshow Plays › In Window**.

- **⇧⌘↩** always plays full screen.
- **⌘⌥↩** always fills the window.

Arrow keys, Space and Enter move through the slides, and **Esc** ends the show.

Sending the file instead? Whoever opens it gets the same slides in their browser, with ‹ ›
buttons and arrow-key navigation, and nothing to install.

## Light or dark

PPTD follows your computer's light or dark appearance. To pick one for PPTD alone, choose
**View › Appearance › Light** or **Dark** (**System** goes back to following the computer).
The agent pane switches with it. Your decks keep their own colours either way.

## Keyboard

| Keys | Action |
|---|---|
| ← → ↑ ↓, PageUp / PageDown | previous / next slide |
| Home / End | first / last slide |
| ⌘↩ | slideshow, in the mode chosen in View › Slideshow Plays |
| ⇧⌘↩ | full-screen slideshow |
| ⌘⌥↩ | slideshow in the window |
| In a slideshow: Enter / Space | next slide (Shift+Enter, Backspace: previous) |
| In a slideshow: Esc | end the slideshow |
| ⌥⌘S | slides drawer |
| ⌘J | agent |
| In the agent: Shift+Enter | new line (Enter sends) |
| ⌘Z | undo the last move, drop or revert |
| ⇧⌘C | copy the current slide as an image |
| ⌘R | reload the deck |
| ⌘N | new window, with its own deck and agent |

On Windows and Linux, use **Ctrl** in place of **⌘**.
