# Overview

**PPTD** ("PowerPoint is dead") is a desktop app for presentations you make by asking. Tell it
what you want to say and an AI agent builds the slides while you watch. Then keep going:
"make the headline shorter", "turn this into a chart", "add a slide about pricing". Every
change appears straight away.

Each presentation is a **single HTML file**. It opens in any browser, previews in Microsoft
Teams and needs nothing installed to view, so you can send it the way you'd send a PDF. On a
phone it shows as a smaller copy of the same slide, not a rearranged web page.

## What you can do

- **[Make a deck by asking](./making-decks.md).** Describe it in a sentence; the agent writes
  it and PPTD opens it as soon as it's saved.
- **Change it by talking about what you see.** Every message carries the slide on screen, so
  "make this shorter" means *this* slide.
- **[Edit by hand](./editing-by-hand.md).** Drag slides to reorder them, drop in photos and
  video, copy a slide as an image.
- **Keep your brand.** The agent asks once how your decks should look and uses it from then on.
- **[Pick a style](./making-decks.md#pick-a-style).** Grid, Bold, Folio, Signal, Atelier, Keynote, Mono, Sticker, Playful or Classic
  for the layout, with any brand's colours; switch a finished deck by asking.
- **[Go back to any prompt](./making-decks.md#go-back-to-any-prompt).** Optionally keep every
  prompt with the deck and rewind to any of them.
- **[Present](./presenting.md)** full screen or in the window, with the keyboard.

The agent is [Pi](./pi.md), an open-source coding agent that comes built in. You can use
Claude Code instead if you have it.

## Try one

The deck on the [home page](/) is a real PPTD file. Click or tap the slide (the left third goes back) or use the arrow keys.
You can also [open it on its own](pathname:///demo/pptd-demo.pptd.html) and save it: it's the
whole presentation, in one file, with no scripts.

## Platforms

PPTD runs on **macOS** (Apple Silicon), **Windows** (x64) and **Linux** (x64). The macOS app
gets the most use; the Windows and Linux builds are newer. See
[Getting started](./getting-started.md) for downloads.
