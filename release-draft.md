# PPTD v1.5.0

- **More varied decks.** The agent now chooses each slide's layout for what the slide says (numbers as big figures, a process as steps, options as a comparison, a voice as a quote) instead of filling deck after deck with the same three cards. It plans a layout for every slide with the outline, avoids repeating one on neighbouring slides, and checks the finished deck for layouts it leans on before handing it over.
