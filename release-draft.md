# PPTD v1.4.0

- A deck the agent makes now opens in the window you asked in, whatever folder it saves to.
  Before, with two windows open, a new deck could open in the other window and replace the
  deck shown there, while the window you were working in stayed empty.
- The agent starts every new deck from PPTD itself, so the deck appears straight away and
  starts out as its style really looks: the style's fonts, spacing and details, with your
  brand's colours.
- When a reply ends with no deck on screen after the agent wrote files, PPTD asks the agent
  once to show the deck it made.
- The agent applies a style faithfully first, then changes only what you ask for. A bigger
  title stays in the style's weight and letter-spacing, and nothing from another style creeps
  in.
- The agent says which style and brand it used. Ask for a style's own colours ("use mono in
  its own colours") to get the look shown in its picture.
- Prompt history for Claude Code no longer misses a prompt now and then.
- Style pictures now show each style's secondary text colour as designed.
